# Student Performance Analysis System

A beginner-friendly Python project for maintaining student records,
calculating performance, saving data in CSV, and displaying Matplotlib charts.
It includes both a terminal application and a browser-based website.

## Features

- Add, view, search, update, and delete student records.
- Store four marks for every student: Python, Mathematics, English, and
  Computer Science.
- Calculate total marks out of 400, average marks out of 100, percentage, and
  grade.
- Find the highest- and lowest-scoring student. Ties are displayed together.
- Generate charts for an individual student's marks, student average
  comparisons, and class subject averages.
- Use the Flask website to add, search, update, and delete records in a browser.
- Save changes automatically and with the menu's save option.
- Load saved records on startup. The CSV file is created with a header if it is
  missing.

## Grading criteria

The grade is based on the student's average mark (equivalent to the percentage
because all four subjects have equal weight):

| Average / percentage | Grade |
| --- | --- |
| 90 to 100 | A+ |
| 80 to below 90 | A |
| 70 to below 80 | B |
| 60 to below 70 | C |
| 50 to below 60 | D |
| Below 50 | F |

The total is the sum of all four marks, out of 400. The average is total
divided by four, out of 100. Percentage is total divided by 400, multiplied by
100.

## Files

- `main.py` — application and menu.
- `web_app.py` — Python website server and JSON endpoints.
- `students.csv` — saved records; this starts with column headings only.
- `templates/index.html` and `static/` — browser page, styles, and interactions.
- `requirements.txt` — Flask and Matplotlib dependencies.

The application creates `students.csv` automatically if it has been removed.
The CSV is written beside `main.py`, so running the program from another
directory still uses the correct data file.

## Installation

Use Python 3.9 or newer. Open a terminal in this project folder and install
the dependencies:

```bash
python -m pip install -r requirements.txt
```

If your system uses `python3` instead of `python`, use:

```bash
python3 -m pip install -r requirements.txt
```

## Run

From the project folder:

```bash
python main.py
```

On systems using `python3`:

```bash
python3 main.py
```

Choose menu option `14` to save and exit. Add, update, and delete operations
also save immediately.

## Run the website

The browser version uses the same CSV file and the same grading calculations.
It provides a web form for student records and displays Matplotlib charts as
images generated by the Python server.

Install the dependencies if you have not already:

```bash
python -m pip install -r requirements.txt
```

Start the website from this folder:

```bash
python web_app.py
```

Open the address printed by Flask in your browser. In Replit, open the
**Student Performance Analysis System** web preview. The terminal program
(`python main.py`) remains available separately. Both versions read and write
the same `students.csv`.

The website validates names, unique roll numbers, and marks from 0 to 100.
Creating, editing, and deleting a record writes the CSV immediately.

**Privacy note:** this demonstration does not include accounts or access
controls. Use fictional/sample student details for public previews; do not
publish real student marks or personal information.

## Testing the features

For the terminal version:

1. Choose `1` and enter a unique roll number, a name, and four marks.
2. Choose `2` to see all records; choose `3` to search using the roll number.
3. Choose `4` to update the name and/or marks. Press Enter to keep each
   existing value.
4. Choose `5` to delete a record and confirm with `y`; enter `n` to cancel.
5. Choose `6` to view a student's total, average, percentage, and grade.
6. Choose `7` and `8` to view the highest- and lowest-scoring students.
7. Choose `9` for a student's subject chart, `10` for student average
   comparisons, and `13` for class subject averages and their chart.
8. Choose `11` to save manually. Exit with `14`, then start the program again
   to confirm the CSV records load automatically.
9. Try a blank name, a repeated roll number, text instead of a mark, and marks
   below 0 or above 100. The program will explain the problem and ask again.
10. To test empty-state messages, use a separate copy of the project folder
    with an empty/header-only `students.csv`.

For the website, open the Replit web preview or start `python web_app.py`, then
add a record in the browser. Check that it appears in the table and
summary, search for it, edit it, open each chart, and delete it after
confirming. Restart the website and verify the CSV-backed data is still
available. Try a duplicate roll number and marks below 0 or above 100 to see
the validation messages.

No sample records are hardcoded. The active workspace `students.csv` keeps any
records already saved there. The college-submission ZIP uses a header-only copy
so saved workspace records are not exported.

## Python concepts demonstrated

- **List:** stores the collection of student records.
- **Dictionaries:** each student record stores the roll number and name, and a
  nested dictionary stores marks by subject.
- **Tuple:** stores the fixed subject names.
- **Functions:** separate record, calculation, persistence, display, and
  chart operations.
- **Loops and conditionals:** drive the menu, validate input, search records,
  and assign grades.
- **Exception handling:** catches invalid numeric marks, missing/unreadable
  CSV files, file write errors, and end-of-input.
- **CSV module:** reads and writes student records.
- **Matplotlib:** draws the three requested bar charts.
- **Flask:** serves the website and validates browser requests using Python.
- **HTML, CSS, and JavaScript:** provide the browser interface; the Python
  terminal app remains available as `main.py`.
